# 创作工作台桌面验收记录

日期：2026-10-23

## 本轮目标

把创作入口从文字填表改为可视化选择流程，并形成“方向 → 角色 → 场景 → 生成”的连续工作流。

## 已验证

- 方向：6 套独立样片，支持原创角色、角色资产和参考图三种入口；角色资产与参考图均改为真实缩略图卡片选择，选择后同步主预览和身份锁定，不再依赖下拉框辨认名称。
- 角色：身份、面部、发型、形体和造型按分类选择；面部、发型、形体和造型均提供同一成年角色的真实视觉对比板，不再使用低质量的 CSS 假人物图。
- 场景：4 套独立场景样片，并保留自定义场景；已有场景资产同样改成带母版预览的卡片选择，不再退回下拉框。
- 交付：人物写真、角色设定、剧情场景、封面海报、系列角色图、动态关键帧六类交付；可选择镜头、视觉质感、锁定项、生成质量和候选数量。
- 联动：系列角色图自动切换为全身造型和 4 张候选；动态关键帧自动切换为全身造型和 2 张候选。
- 候选：多候选不再重复提交同一条提示词，而是按交付类型自动生成构图、情绪、光影、连续性或动作阶段的受控变化。
- 状态：生成前明确显示图片模型是否就绪；未连接模型时只允许保存方案。
- 闭环：生成前明确展示“候选 → 审片 → 母版 → 动态”，避免把后续动作藏在其他模块。
- 后续：候选在创作页内直接完成主版本选择、2–4 张同屏对比、定向修订、母版晋级和动态延展，不再要求跳转生产域寻找审片入口。
- 溯源：每张候选展示候选策略、模型、实际画幅、参考图摘要和版本，便于判断差异来源。
- 一致性：已有角色与人物参考图不再叠加入口默认脸型、肤色或发型；角色身份、人物主参考和场景辅助参考分别进入明确的生成职责。
- 额度控制：图片模型已连接时仍可“仅保存方案”，不会调用生成接口；确认后再单独生成候选。
- 资产沉淀：已确认且权利合格的原创候选可一键建立角色档案、绑定角色主参考、创建角色资产包，并把角色和资产包回写当前创作任务，后续可直接换场景、镜头或继续做动态。
- 桌面端：四个步骤均在唯一正式 App 中逐页操作验证。
- 自动化：51 个测试文件、220 项测试全部通过；正式构建与 Mac 打包通过。
- 发布：`release` 中仅保留一个当前 App。
