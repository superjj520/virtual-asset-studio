# 虚拟资产创作工作台：界面规范（第一版）

## 1. 设计目标

这是一个本地运行、以项目为边界的创作后台。界面不承担“展示氛围”的任务，而要让创作者在每一次操作中清楚知道：自己位于哪个项目、正在管理什么对象、下一步应做什么、哪些内容已经锁定。

设计原则：

- **项目始终可见**：顶部持续显示当前项目；所有资产、任务、候选与模板围绕项目关联。
- **先对象，后动作**：先选角色、资产包、任务或候选，再在上下文中执行操作，避免在多张卡片间猜入口。
- **密度服务判断**：状态、数量、验收标准用列表与数据块呈现；图片预览只出现在需要对比的地方。
- **一页一主任务**：每个页面仅有一个强调按钮，其余是次级操作。
- **渐进呈现**：新用户先走“建立项目 → 建立创作基线”；专业设置保留在对应工作域，而不是堆在首页。

## 2. 信息架构与操作路径

第一层固定为四个工作域：

| 工作域 | 用户问题 | 二级模块 | 主要产出 |
| --- | --- | --- | --- |
| 创作 | 这次要做什么，什么必须不变？ | 项目总览、建立任务、创作卡 | 可验收的创作任务 |
| 资产 | 我有哪些可复用且已确认的资产？ | 角色、资产结构、资产库 | 角色档案、资产包、母版 |
| 生产 | 哪一个候选应被确认，下一步卡在哪里？ | 候选与审片、镜头与视频、生成队列 | 已确认候选与生产记录 |
| 模板 | 哪套经验可以复用？ | 创作配方、画面方向、学习来源 | 已验证配方与视觉范式 |

核心路径：建立项目 → 在“建立任务”写一句目标与不可漂移项 → 生成创作卡 → 导入或绑定资产 → 生产候选 → 审片确认 → 锁定母版 / 导出。

## 3. 版式网格

- 桌面基准：1440px 宽度；内容区最大宽度 1440px，最小左右留白 32px。
- 左侧工作域栏：224px 固定宽度；顶部上下内边距 20px；主导航项高 44px。
- 顶部项目栏：64px 固定高度；页面内容从栏下开始。
- 主内容：12 列网格，列间距 20px；普通页面使用 8 / 4 或 7 / 5 分栏，卡片清单使用 3 或 4 列。
- 页面内垂直节奏：标题区 32px，下一个区块 24px，卡片内边距 20px。
- 小屏小于 768px 时，侧栏变为吸顶四域导航，所有双栏退为单栏。
- 页面说明只保留“当前对象、当前状态、下一步”三类信息；补充解释放入详情或帮助，不放在首屏。

## 4. 字体与间距令牌

| 名称 | 规格 | 用途 |
| --- | --- | --- |
| 页面标题 | 28px / 36px，600 | 每页一个主标题 |
| 区块标题 | 18px / 26px，600 | 卡片组、面板标题 |
| 卡片标题 | 15px / 22px，600 | 角色、任务、资产名称 |
| 正文 | 14px / 22px，400 | 说明、表单内容 |
| 辅助信息 | 12px / 18px，500 | 状态、标签、字段名 |
| 微型标签 | 11px / 16px，600 | 域名、步骤、数量 |

只使用以下间距：4、8、12、16、20、24、32、40、48px。禁止在页面内新增随意的间距值。

## 5. 组件合同

| 组件 | 固定规格 | 使用规则 |
| --- | --- | --- |
| 主按钮 | 36px 高，左右 14px，圆角 6px | 一页只保留一个主按钮 |
| 次按钮 | 36px 高，描边样式 | 次要行为、切换视图 |
| 输入框 / 选择框 | 40px 高，圆角 6px | 标签置于控件上方，必填项明确标注 |
| 多行输入 | 最小 104px 高 | 用于目标、验收条件、不可漂移项 |
| 数据块 | 最低 112px，高度一致 | 仅放一个指标和一个解释 |
| 工作卡 | 内边距 20px，边框 1px | 标题、状态、简短摘要、一个主动作 |
| 空状态 | 最小 220px | 说明“为什么为空”和唯一下一步 |

## 6. 视觉与状态

- 画布 `#F7F8FA`，基础表面 `#FFFFFF`，弱表面 `#F2F4F7`。
- 正文 `#182230`，辅助文字 `#667085`，分割线 `#EAECF0`。
- 主操作蓝 `#2E5BFF`，悬停 `#2348D8`，弱强调 `#EEF2FF`。
- 成功 `#027A48`，警告 `#B54708`，风险 `#B42318`。颜色永远配合文字或图标表达状态，不能只靠颜色。
- 键盘焦点为 3px 浅蓝外环；卡片悬停只改变边框与轻微阴影，不做跳动动画。

## 7. 页面模板

1. **总览页**：页面标题 + 四域交付进度 + 当前阻塞 + 任务列表 + 唯一下一步。四域状态必须由项目真实数据计算，不允许用静态功能卡冒充进度；禁止将所有系统功能卡片化平铺。
2. **目录页（角色 / 资产 / 模板）**：标题栏 + 筛选与主动作 + 左侧分类 / 中部清单 / 右侧详情（宽屏）。
3. **工作台页（创作 / 审片 / 镜头）**：标题栏 + 主要编辑区域 + 辅助检查区域；生成或确认操作固定在当前对象上下文。
4. **首用页**：把建立项目与开始创作分开表达，明确两种路径，不要求用户先理解整个后台。

## 8. 验收清单

- 同一屏幕中，标题、字段、按钮、卡片的字号与高度来自令牌表。
- 用户在任何页可判断当前项目、当前工作域、当前二级模块。
- 无项目、无资产、无任务、无候选时均给出唯一可执行的下一步。
- 项目总览能回答“现在在哪一步、为什么卡住、点击哪里继续”；创作、资产、生产、模板不能各自成为信息孤岛。
- 同一判断只保留一个权威入口：图片评分与母版晋级归“审片与母版”，素材详情只管理文件、权利、归档和视觉理解。
- 主导航、表单、按钮可用键盘聚焦；颜色对比满足日常桌面阅读。
- 新功能先套用本规范的页面模板与组件合同，再进入实现。
