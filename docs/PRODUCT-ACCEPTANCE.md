# 创作工作台产品验收清单

更新时间：2026-10-25

## 当前目标

在暂不依赖真实图片模型的前提下，将创作模块完成为可以与竞品正面比较的本地产品流程：用户主要做选择，系统负责继承角色、造型、场景、版本和资产关系。

## 状态定义

- `待实现`：还没有完整产品路径。
- `实现中`：已有局部能力，但流程、持久化或视觉尚未闭环。
- `待验收`：代码与自动测试完成，仍缺真实应用验收。
- `已验收`：自动测试、真实应用、重启恢复和资产回流全部通过。
- `阻塞`：存在明确外部依赖，并记录阻塞原因。

## 已验证基线

- 创作首页已经按结果类型提供角色塑造、单张画面、剧情场景、系列镜头四个入口。
- 剧情场景已经形成“选择场景 → 选择方向 → 单变量调整 → 保存资产”的本地流程。
- 角色创作具备选择式步骤、草稿恢复和跨创作复用基础。
- 最近一次完整自动验证通过 60 个测试文件、271 项测试，并成功打包唯一 Mac 应用。

这些结果是当前基线，不代表九项验收全部完成。

## 每项任务的执行模板

DeepSeek Harness 或其他开发代理每次只领取一个编号，并按以下顺序执行：

1. 写出当前行为、目标行为和不改动范围。
2. 找到最小代码边界并补充失败测试。
3. 实现选择式交互，不新增长表单。
4. 运行相关测试，再运行完整测试和构建。
5. 在真实 Mac 应用中走完该路径。
6. 退出并重启应用，验证状态恢复。
7. 检查保存结果的角色、场景、任务、版本和来源关系。
8. 记录截图、测试结果、已知问题和回滚提交。
9. 使用独立中文提交信息提交，不直接合并 `main`。

## 产品完成定义

只有满足以下全部条件，才能宣布本轮目标完成：

- C1–C4、R1–R3、Q1–Q2 全部标记为“已验收”。
- `npm test`、`npm run build`、`npm run package:mac`、`npm run verify:release` 全部通过。
- 真实 Mac 应用完成四条端到端路径，没有黑屏、断路、重复入口或无法返回的步骤。
- 重启后能够恢复任务，已保存资产可以继续复用。
- `release/` 中仅存在唯一正式应用。
- 没有把未接入的模型、云服务或视频能力描述为已完成。
