# R28 · 搜索跨全部分类（2026-11-02）

## 问题

云端图库的搜索框只在**当前选中的分类**里搜：

```ts
.filter((item) => cloudKind === "all" || item.kind === cloudKind)
```

用户停在「人像 1499」分类里搜 `denim`，结果为零——因为牛仔装全在「动漫衣装 1320」或「服装 1847」里。搜索框旁边是 7 个分类按钮，看起来像是在缩小范围，实际上是把自己关在门外。

真实场景里这很常见：用户先点「人像」看了看，然后想找件牛仔外套，直接在搜索框里打字，什么都搜不出来，会以为库里没有。

## 改法

**搜索词非空时，分类条件失效**：

```ts
const cloudSearching = cloudQuery.trim().length > 0;
.filter((item) => cloudSearching || cloudKind === "all" || item.kind === cloudKind)
```

同时补三件事，避免「分类按钮还亮着但结果跨了全库」的困惑：

1. **搜索时分类按钮全部不高亮**（`!cloudSearching && cloudKind === kind`）
2. **点任意分类按钮会清空搜索词**，回到「按分类浏览」的语义
3. **状态行明说**：`48 张已显示 / 匹配 150（搜索跨全部分类）（库内 6980）`

## 一个设计取舍

另一种做法是搜索时自动把分类切到「全部」，让按钮状态和结果一致。没选它，因为那会**改掉用户自己选的状态**——用户搜完清空搜索词，期望回到原来那个分类，而不是被丢掉。现在的做法是搜索期间临时忽略分类，打完字回到分类浏览时分类还在。
