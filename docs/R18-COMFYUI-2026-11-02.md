# R18 本机 ComfyUI 接入（2026-11-02）

## 为什么做

对标库 anhao 有一个 ComfyUI 原生插件（4 个节点 + 4,345 条中文弹窗选图器 + 工作流导入导出）。
我们之前只有一句注释写着「ComfyUI 网关可在此契约后接入」，等于没有。
对创作者来说，这一项的差别不是「多一个模型」，而是「能不能用自己已经调好的 LoRA、ControlNet 和自定义节点出图」。

## 这一版做了什么

新增一个独立的 provider，走 ComfyUI 官方 HTTP 接口，不依赖任何第三方网关：

| 接口 | 用途 |
| --- | --- |
| `POST /prompt` | 把工作流入队，拿 `prompt_id` |
| `GET /history/{prompt_id}` | 轮询，直到 `outputs` 里出现图片或 `status` 报错 |
| `GET /view?filename=&subfolder=&type=` | 取回真实图片字节 |

### 内置工作流

不填工作流时用内置模板：`CheckpointLoaderSimple → 双 CLIPTextEncode → EmptyLatentImage → KSampler → VAEDecode → SaveImage`。
参数通过占位符注入，用户不需要懂节点编号：

| 占位符 | 来源 |
| --- | --- |
| `{{prompt}}` / `{{negative}}` | 当前创作的正向与负向提示词 |
| `{{seed}}` | 创作卡上的随机种子（留空则每次随机） |
| `{{width}}` / `{{height}}` | 当前画幅的真实像素 |
| `{{steps}}` | 画质档：高清 28，标准 20 |
| `{{checkpoint}}` | 设置页填的 checkpoint 文件名 |

整串就是一个占位符时保留原始类型——`{{width}}` 必须是数字，否则 ComfyUI 会拒绝节点输入。

### 自定义工作流

粘贴 ComfyUI 导出的 **API 格式** JSON 即可覆盖内置模板，支持同样的占位符。JSON 不合法或不是对象时直接报错，不静默回退到内置模板——否则用户会以为自己的工作流生效了。

### 配置项与校验

设置页新增「本机 ComfyUI / 直接驱动工作流」区块：服务地址、checkpoint 文件名、工作流 JSON。

- 地址必须是 http/https 完整地址；留空即关闭，同时清空 checkpoint 与工作流，避免下次误连。
- 工作流在保存时就校验 JSON，不让坏配置留到出图时才炸。
- 地址为空时不产生任何网络请求。

### 失败处理

- `/prompt` 被拒：带出 ComfyUI 的原始响应片段（前 300 字符）。
- 缺 `prompt_id`：带出 `node_errors`，能定位到是哪个节点参数不对。
- 节点执行失败：从 `status.messages` 里提取 `exception_message`，例如 `mat1 and mat2 shapes cannot be multiplied`。
- 超时：默认 10 分钟，轮询间隔 1 秒，超时提示检查队列是否卡住。

## 路由与可用性

- `ProviderId` 新增 `comfyui`；模型清单新增「本机 ComfyUI」（任务：人像 / 场景 / 系列 / 修订，六种画幅全支持，本机显卡不计费）。
- 能力路由里 `comfyui` 排在 `image` 优先级最后：配了云端服务就继续用云端，一家都没配时才轮到本机。
- 未配置时的提示语是「尚未配置 ComfyUI 地址。」，和「尚未配置 xxx 密钥。」区分开——它确实不需要密钥。

## 已知限制

- 这一版只做**纯文本出图**。参考图上传（`POST /upload/image` + `{{reference_image}}` 占位符）留到「可分享配方包」一起做——它需要把六格参考板作为图片喂给工作流，正是配方包要解决的同一件事。
- 没有做 `/object_info` 拉取，checkpoint 需要手填。填错时 ComfyUI 的报错会原样回显，能定位但不够友好。
- 内置模板用 `euler` + `normal`，没有暴露采样器选择；需要别的采样器时走自定义工作流。

## 截图取证方法（复现用）

macOS 上 spawn Electron 时必须显式清空 `ELECTRON_RUN_AS_NODE`，否则进程以 node 模式启动，不暴露 CDP 端口：

```js
spawn(electronBin, [".", `--user-data-dir=${tmp}`, "--remote-debugging-port=9445"], {
  cwd: project,
  stdio: "ignore",
  env: { ...process.env, ELECTRON_RUN_AS_NODE: "" },
});
```

跑之前先 `npm run rebuild:native:electron`；跑完 `npm test` 会自动 rebuild 回 node ABI。
