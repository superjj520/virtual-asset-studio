## 二、ComfyUI 侧能力

逐项读 anhao 源码（`comfyui_plugin/nodes.py`、`routes.py`、`docs/comfyui-workflow-parameters.md`）后对照。

| 能力 | anhao | 我们 | 证据 |
|---|---|---|---|
| 图库选图节点 | 4 个 | **7 个** | `object_info` 实读，`docs/R40` |
| 节点内弹窗选图 | 有 | 有 | `gallery_smoke.mjs` 13 项 |
| 服务端图库路由 | 2 个 | **3 个**（sites/catalogue/thumb） | `routes_test.py` 六组断言 |
| 尺寸模式/宽高/镜像 | 有 | 有 | `contract_test.py` 实读契约 |
| 姿势→深度图切换 | `use_depth` 按路径替换 | `use_depth` 按 id 跨库匹配（100%） | `depth_test.py` 1439/1439 |
| 节点输出提示词 | 中/英 | 中/英 | `prompt_test.py` |
| 画风预设 | 有（`style_preset`） | 有（12 种，与客户端一致） | `prompt_test.py` 硬断言两边集合相等 |
| 工作流参数编辑 | 有 | 有 | `verify:panel` 12 项 |
| 参考图组合声明 | 有 | 有 | `workflow-parameters.test.ts` |
| `.api.json` 导入导出 | 有 | 有 | `settings:read/export-workflow-file` |
| 缩略图 switch 深度版（`depth=1`） | 有 | **没有这个参数** | 见下方说明 |

关于最后一项：anhao 的 `depth=1` 是在同一张姿势卡片上把缩略图换成深度版。我们的深度库是**独立站点**（`site=depth`，1,439 条），用户切到「深度」分类直接选，功能等价、入口不同。**判为入口差异，不是能力缺失。**

## 四、缺口（**需要你决定，我做不了主**）

| 缺口 | 为什么卡住 |
|---|---|
| 男性单人姿势 = 0（2026-11-03 修正） | **原先写的「男性素材 = 0」是错的**，那是只看字段名得出的结论，没看图。实抽 7 张核对：单人组（上半身 400 + 全身标准 365 + 全身性感 399 ＝ 1,164 条）确实全是女性人偶；但**双人组 275 条里有男性主体**——`pair60_P022_front`「双腕过头交叠・抱膝」正面就是男性胸肌特写，`pair60_P001_front` 是男女配对。所以准确的缺口是「**没有以男性为唯一主体的单人姿势库**」，不是「一张男性都没有」。人像 1,499 条与服装 1,407 条确实全是女性（这两项按字段判断成立）。`open-pose-costume` 有 13 组男性单人姿势，但授权写死「不可商用、再分发需书面授权」。需你决定：另找可商用源，还是自建。 |
| 真实出图验证身份一致性 | 要有可用密钥，约 $0.15/张。 |
| 批量路径的深度图 | 要改 SQLite 表结构（加列 + 旧数据兼容），属数据迁移，没敢混进功能提交。 |
| 真实 ComfyUI 出图质量 | 本机无 checkpoint；且当前系统代理 `127.0.0.1:10900` 没在跑，pip 装不了 torch，重搭 ComfyUI 环境也要先解决这个。 |

## 五、验证入口

| 命令 | 覆盖 | 需要网络 |
|---|---|---|
| `npm test` | 95 文件 / 505 项 | 否 |
| `npm run verify:panel` | 参数面板真机 12 项 | 否 |
| `npm run verify:nodes` | 节点契约/提示词/深度匹配/路由/弹窗 | 否 |
| `npm run verify:nodes -- --online` | 上面 + 六个上游源 | 是 |
| `npm run package:mac` | 打包 + 唯一性校验 | 否 |
| `npm run smoke:packaged` | 四入口能进入对应创作 | 否 |
| `npm run smoke:restore` | 上面 + 退出重启后能恢复上次创作 | 否 |

`smoke:packaged` 只到「四个入口都能进」。`smoke:restore` 用同一个 user-data 目录跑两遍：第一遍走一遍新建创作，第二遍重启后检查启动页有「继续上次创作」、点进去能回到原阶段。2026-11-03 实跑两阶段都过。
