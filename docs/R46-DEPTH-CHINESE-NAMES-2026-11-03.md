# R46 深度图改用中文姿势名

上一轮结尾留了一条：「深度库 1,439 条标题还是日文，要人工校对」。

后来想通了——**根本不用翻译**。

## 为什么不用翻

R35 验证过一件事：深度库和姿势库是**同一批 1,439 张图的两套名字**，`id` 完全一致（`full_sexy_P001_front` 在两边都存在，匹配率 1439/1439）。区别只是：

| | 姿势库（anhao） | 深度库 |
|---|---|---|
| 名字 | `S形站姿・胯部侧顶` | `S字立ち・腰を横に突き出す` |
| 角度 | `正面` | `正面` |
| 分类 | `站姿` | `立ち` |
| 体系 | `全身单人・性感系` | `全身1人・セクシー系` |

姿势库本来就有中文。按 `id` 取过来替换就行——**机翻有风险，借同 id 的中文名零风险**。

## 改动

`electron/services/reference-library.ts` 的 `depthItems`：

```ts
const poseById = new Map(poses.map((row) => [row.id, row]));
const depthItems = depths.map((row) => {
  const pose = poseById.get(row.id);
  return {
    id: `depth-${row.id}`,
    title: pose
      ? `${pose.姿势名称 ?? row.ポーズ名 ?? row.id} · ${pose.角度 ?? row.アングル ?? "视角"}`
      : `${row.ポーズ名 ?? row.ポーズ番号 ?? row.id} · ${row.アングル ?? "视角"}`,
    category: pose?.分类 ?? row.分類 ?? "姿势深度",
    tags: [pose?.体系 ?? row.系統, pose?.角度 ?? row.アングル].filter(Boolean),
    ...
  };
});
```

查不到同 id 就退回日文——姿势库挂了、或者上游加了新深度图还没有对应姿势时，不至于显示空白。

## 效果

- 深度图卡片标题：`S形站姿・胯部侧顶 · 正面`（原来是 `S字立ち・腰を横に突き出す · 正面`）
- 分类：`站姿`（原来是 `立ち`）
- 标签：`全身单人・性感系`（原来是 `全身1人・セクシー系`）
- 搜索「站姿」「性感」现在能命中深度图

## 门禁

- `npx tsc --noEmit` 无输出
- `npm test` **95 文件 / 505 测试全过**（新增 1 项：同 id 时用中文名、且不含 `S字立ち`）
- build / package:mac / smoke:packaged 全过，残留进程 0

## 边界

**只覆盖 id 能对上的那些。** 如果上游深度库新增了姿势库还没有的条目，那些仍然是日文。这不是缺陷，是「没有中文源可用」的必然结果——真出现了只能人工翻或者等上游补。
