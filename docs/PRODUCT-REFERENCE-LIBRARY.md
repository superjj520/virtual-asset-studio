# 产品方向：参考库 + 配方，而不是复刻图库

日期：2026-11-01

## 一句话

RuiC 的图鉴解决“去哪里找参考”；我们要解决“怎么把参考变成一张可交付、可复用、可追源的画面”。

## 三层商业逻辑

1. **底座**：本地静态参考库提供准确性和方向。人物、服装、姿态、场景分开找，不靠模型猜。
2. **中间层**：组合模型 + 固定模板 + 分槽提示词，把“四张参考”压成一条可解释的生成配方，降低随机试错的成本。
3. **产品层**：配方本身资产化。用户保存的不是四张图，而是一套可复用的视觉配方，可以继续生成同系列、换成视频、导出给协作者。

护城河不在图片数量，而在：

- 参考图有语义槽位；
- 配方能复用、能比较、能追源；
- 生成结果能回到资产库继续生产。

## 从 RuiC 学什么

- **分角色参考**：脸、衣装、姿态不混在一张图里。
- **按组浏览**：一组姿态带五个视角，选的是“组”，不是散图。
- **标签即索引**：标签同时用于展示、筛选、搜索，每个筛选项带数量。
- **首屏先决策**：数量、分类、搜索、结果计数先出现，图片后出现。
- **批量与键盘**：桌面高密度网格，方向键切角度，上下键切组。
- **工程校验**：数量、标签、尺寸、断链都能自动验。

## 不抄什么

- 不做纯静态图鉴首页；我们的首页是创作入口。
- 不把第三方素材打进 App 或对外分发。姿势、衣装明确禁止再分发；人像是 CC0，但仍需保留来源。
- 不在第一版做三语全量翻译；先把中文创作路径跑通。
- 不把参考库和用户资产库混成一个列表。两者权利、生命周期、复用方式不同。

## 产品结构

### 1. 参考库（只读）

三个目录：`人物 / 服装 / 姿态`，场景作为第四类可后续加入。

每个条目：

- 名称、分类、标签、来源、许可；
- 主图 + 多视角/变体条；
- “加入配方”动作，不直接进入生成。

浏览规则：

- 顶部：目录切换、总数、分类 chips；
- 第二行：搜索 + 属性筛选 + 结果计数；
- 网格：桌面 5–6 列，移动 2 列；
- 卡片：图、编号、名称、2–4 个关键标签、许可角标。

### 2. 配方台（核心）

四个槽位：身份 / 服装 / 姿态 / 场景。

- 每个槽位只接受对应语义的参考；可从参考库、角色资产、用户资产选择。
- 槽位可锁定；一次只改一个槽位。
- 配方摘要用一句话说清“变了什么、没变什么”。
- 模型能力提示：多参考模型显示“四层都会读”；单参考模型明确显示“只锁定身份，服装/姿态/场景按文字走”。

### 3. 生成与审片

- 先比较多方向，再选主方案；单变量调整。
- 审片门禁：单幅、无拼贴/边框、身份一致、槽位语义命中、权利可追。
- 失败要能定位：网络、配额、权利、槽位不匹配分别给不同下一步。

### 4. 配方资产

把配方保存为可复用资产，而不是只保存图片：

- 配方名、四槽位、提示词、负面词、模型、画幅、种子；
- 来源资产 ID、许可、生成记录；
- 可继续生成同系列、换姿态/场景、进入视频；
- 可导出“配方卡”（文字 + 缩略图 + 来源），不打包第三方原图。

## 数据模型（最小）

```text
ReferenceItem      id, catalog, groupId, title, tags[], license, sourceUrl, images[]
ReferenceGroup     id, catalog, title, angleOrder[], itemIds[]
LookRecipe         id, name, slots[{role, assetId}], prompt, negative, modelId, aspect
RecipeRun          id, recipeId, modelId, appliedRefs[], resultAssetId, status
```

`slots` 的 `role` 固定为 `identity / wardrobe / pose / scene`；顺序就是送模顺序。

## MVP 顺序

1. **本地参考库索引**：读取已下载目录的 JSON，显示数量、分类、标签、搜索；不搬图进 Git。
2. **参考库 → 配方台**：三个目录都能“加入配方”，四槽位可替换。
3. **配方模板**：先做 10 套固定模板（如“冷清东方 · 长衫 · 回眸 · 夜庭”），每套带完整提示词和负面词。
4. **多参考生成**：优先多参考模型；单参考回退必须明确标注能力边界。
5. **配方资产化**：保存、复用、导出配方卡。
6. **视频契约**：同一配方接图生视频，记录首帧和运动提示词。

## 验收指标

- 首次可用图时间（从打开到选出一张可用图）。
- 一次生成的有效率（不需要重试的比例）。
- 配方复用率（同一配方生成 ≥2 次的比例）。
- 槽位命中率（人工审片：身份/服装/姿态/场景各是否进入画面）。
- 失败可解释率（用户能看到具体下一步的比例）。
