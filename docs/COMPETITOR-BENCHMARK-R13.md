# 竞品对照与产品打磨基线（2026-10-27）

## 对标对象
- ourdream：六步创作向导、单步单主决策、大幅视觉选择
- 即梦/可灵：中文创作起点、模板化任务、结果再编辑
- Midjourney：参数少、候选比较、变体与放大
- Leonardo：资产库、模型选择、生成历史复用

## 我们的差距
1. 创作起点仍是四张卡，缺少“继续上次”和模板/资产入口。
2. 确认页信息密度高于竞品，模型与画幅仍偏技术。
3. 结果页能比较和逐镜调整，但缺少明确的“采用/淘汰/下一步”。
4. 资产保存后版本链与复用入口已具备，绑定写回仍不完整。
5. 移动端首屏常被全局底栏压缩，主行动位置不稳定。
6. 没有真实竞品级出图，但本地流程可先做到不依赖模型。

## 打磨顺序
P0 起点与恢复 → P1 确认页减负 → P2 结果页闭环 → P3 资产复用 → P4 移动端 → P5 视觉统一。

边界：不以真实出图作为本轮前置条件；不伪造结果。
